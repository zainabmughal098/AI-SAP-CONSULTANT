Task Objective

The objective of Task 2 was to develop the retrieval stage of the RAG pipeline. This component accepts a natural language SAP query, converts it into an embedding, searches the Pinecone vector database, ranks the best matching records, and builds a combined retrieval context for later use by an LLM.

What Was Implemented

  • Query processing module to clean and validate user input.
  • Embedding generation using the same SentenceTransformer model as Task 1.
  • Pinecone retrieval module for semantic vector search.
  • Metadata filtering support for fields such as Module and Document Type.
  • Result ranking based on similarity score.
  • Context builder to merge retrieved records into a single prompt-ready context.
  • Logging for query, embedding generation, search time, result count, similarity scores, and context size.
  • Error handling for empty queries, missing metadata, and retrieval failures.

How the Retrieval Engine Works

Step Description
User Query The user enters a SAP-related question like “Explain ME21N” or “Purchase Order release failed.”
Query Preprocessing The query is cleaned by trimming extra spaces and validating that it is not empty.
Embedding Generation The same embedding model used in indexing creates a vector for the query.
Pinecone Search The query vector is used to search Pinecone with top-k similarity retrieval.
Ranking and Filtering Returned matches are sorted by similarity score and optionally filtered by metadata such as module or document type.
Context Builder The best matches are merged into a single retrieved context block that can be given to an LLM later.
